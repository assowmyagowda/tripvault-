# TripVault ✈️

TripVault is a full-stack travel management application built using the MERN stack. It allows users to register, log in, create and manage their trips, add descriptions and ratings, and upload trip photos.

## 🚀 Live Demo

Frontend:
https://tripvault-five.vercel.app/

Backend:
https://tripvault-c1b6.onrender.com/

## 📂 GitHub Repository

https://github.com/assowmyagowda/tripvault-

## ✨ Features

- User registration and login
- Secure authentication
- Create new trips
- View trips on the dashboard
- Edit trip details
- Delete trips
- Add trip descriptions
- Give trips ratings from 1 to 5
- Upload trip photos
- Responsive user interface

## 🛠️ Technologies Used

### Frontend
- React.js
